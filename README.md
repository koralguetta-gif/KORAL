# התדר שלך עכשיו

חבר למוזיקה. בונים שכבה על שכבה – ביט, צלילים, מה באוויר, מילים – וכל בחירה פותחת את הדרך הבאה.
בסוף: שם הסגנון בשפה של מדריך, ושירים אמיתיים שנשמעים ככה.

- האפליקציה: https://koralguetta-gif.github.io/KORAL/
- `index.html` – הקובץ שמוגש (נבנה מ־`src/` עם `python3 src/build.py`, ואז מעתיקים את `src/index.html` לשורש).
- `src/styles.js` – קטלוג 46 הסגנונות והשכבות שבונות כל אחד.
- `src/engine.js` – מנוע הצליל החי (Web Audio).
- `src/app.js` – המסלול המתפצל, כתיבה/דיבור, המדריך, הזיכרון.
- `server/` – Supabase Edge Function `tadar` (פרויקט koral): תיווך ל־Deezer וזיכרון רגעים.
